# Guides

Each guide takes one job and walks it from the first click to the result, naming the
decisions on the way and what each one costs. They are written to be read before you
start, and to be followed with the tool open beside them.

The catalog of every tool, a paragraph each, stays in the
[README](https://github.com/Juan-Concepcion/tools4i-docs#features).
